# ADR-0011: Roll out the portable rewrite as an additive parallel path, deprecating phase-by-phase

**Status:** proposed

## Y-Statement

In the context of replacing scientia with a portable Agent Skills implementation
where this change delivers only the wiki→intent authoring half, facing the
choice between declaring the rewrite canonical-and-deprecating-the-bundle-now
versus shipping it alongside, we decided for an additive parallel authoring path
(existing bundle fully supported) with total replacement as the eventual goal
sequenced authoring-first and phase-by-phase deprecation as each portable
replacement passes its evals, and against deprecating the whole bundle now, a
big-bang cutover, or a permanent authoring-only fork, to achieve delivery
continuity and incremental risk while mastering authoring first, accepting
interim non-interop between the produced layout and the OpenSpec execution loop
and a multi-change migration with no committed timeline.
