# ADR-0006: Transfer pipeline state through on-disk artifacts only

**Status:** accepted

## Y-Statement

In the context of the `pipeline-controller` sequencing stages, facing the
choice of how state moves between them, we decided for on-disk artifacts as the
sole inter-stage channel (the controller holds no in-memory state) — and for
the stage-advance marker itself being a package-owned write that `kg_pipeline`
performs **only** after its validators pass, so the controller cannot fabricate
an advance — and against an in-memory pipeline/context object or a hybrid, to
achieve resumability, runtime-agnostic portability, and gate enforcement by
construction (ASR-3, ASR-1, ASR-5), accepting re-parse cost and no rich typed
handoff. Closes the ASR-5 enforcement gap ADR-0007 previously logged as
residual risk.
