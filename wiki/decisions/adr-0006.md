# ADR-0006: Transfer pipeline state through on-disk artifacts only

**Status:** proposed

## Y-Statement

In the context of the `pipeline-controller` sequencing stages, facing the
choice of how state moves between them, we decided for on-disk artifacts as the
sole inter-stage channel (the controller holds no in-memory state) and against
an in-memory pipeline/context object or a hybrid, to achieve resumability and
runtime-agnostic portability (ASR-3, ASR-1), accepting re-parse cost and no
rich typed handoff.
