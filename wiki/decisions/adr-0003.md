# ADR-0003: Model confidence per-claim and quantitatively

**Status:** proposed

## Y-Statement

In the context of a pipeline whose automation decisions must be reproducible,
facing the inadequacy of per-page qualitative confidence and uncalibrated
single LLM scores, we decided for a per-claim quantitative model
(`effective = min(floor, base × multiplier)` when contradicted, else
`base × multiplier`) with the brief's config defaults confirmed, and against
qualitative/pure-LLM/learned models, to achieve a deterministic automation gate
(ASR-4), accepting hand-tuned constants and a heuristic (not probabilistic)
score. Resolves proposal Open Question #4.
