# Implementation Plan

Ordered by dependency, grouped by capability for readability. `@uses-shared:`
marks every task that reads/writes the `Page`/`Link` types ratified by ADR-0001
(`accepted`, so the emit preflight is satisfied). The producer of those types
(task 4) carries `@adr: ADR-0001` instead. No trunk fmt baseline applies (the
`kg_pipeline` package does not yet exist), so there is no item #0.
